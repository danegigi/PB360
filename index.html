About

These tutorials were verified against the live Pitney Bowes docs at docs.shipping360.pitneybowes.com (API portal release v1.0.52, Aug 27 2026). Shipping360 deliberately does not publish per-carrier service/parcel/special-service codes — always fetch them at runtime via the metadata APIs (see Basics → Carrier Metadata). Confirm final values against the official reference and Carrier Catalog before production.
